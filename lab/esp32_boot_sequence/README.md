# Offline classic ESP32 BOOT/EN observation gate

Public-safe, synthetic-only. Run `cd lab/esp32_boot_sequence && python3 -m unittest -v test_sequence_gate.py`. Observations are manually entered, not collected from devices. A candidate is **not** proof of ROM download mode; verify chip identity and ROM logs on owner-operated hardware. ESP32-S2 always routes to separate manual review. Never use this tool to authorize flashing, wiring, or power connections.
